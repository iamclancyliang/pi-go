# Pi 使用说明

**这份文档说的是「Pi 的每项功能怎么用」**，按入口组织：命令行、交互界面、会话、工具、扩展、
模型与厂商、RPC、SDK。每一节给出**前置条件、最小用法、限制与降级行为**。

配套的「有哪些功能」在 `pi-功能清单.md`。

> ## ⚠️ 这是 Pi 的用法，不是 pi-go 的
>
> **pi-go 目前不是可用的产品。** 它只有一个能跑通最小链路的示踪弹：
> ```bash
> cd pi-go && go run ./cmd/pi-tracer
> ```
> 它用假模型和两个只读的假工具，打印一条完整轨迹，用来证明「提问 → 模型 → 工具 → 回答 →
> 事件轨迹 → 会话快照」这条链路通了。**下面所有用法都属于 Pi，不代表 pi-go 已经实现。**

**基准**：`earendil-works/pi` 的 `086c32e7`。用法从该版本的文档与源码读出。

## 一、安装与启动

**前置条件**：Node 环境；至少一个厂商的凭据（API key 或 OAuth 登录）。

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi                                  # 进入交互界面
```

**最小用法**
```bash
pi -p "总结这个代码库"                # 跑一次就退出
pi @README.md "总结这个文件"          # 用 @ 把文件带进上下文
pi -p @screenshot.png "这是什么"      # 图片同理
```

**限制与降级**
- ⚠️ **运行形态由终端状态决定**：`pi` 在终端里进入交互界面；**一旦输出被重定向（接管道、重定向到文件），
  自动降级为打印模式**。想强制打印用 `-p`。
- **没有 `--mode interactive` 这个写法**（参数只认 `text`/`json`/`rpc`），但交互界面**能**通过参数走到：
  `--mode text` + 两端都是终端 + 不加 `--print`，解析出来就是交互界面。
- `--offline` 关闭启动时的联网动作（更新检查、包更新、遥测）。

## 二、交互界面

**前置条件**：标准输入与标准输出都是终端。

**最小用法**：直接打字提问。界面分四块：启动信息、消息区、编辑器、状态栏（工作目录、会话名、
token 与缓存用量、花费、上下文占用、当前模型）。

**编辑器里能做的事**
| 想做什么 | 怎么做 |
| --- | --- |
| 引用项目文件 | 打 `@` 模糊搜索 |
| 补全路径 | Tab |
| 多行输入 | Shift+Enter（Windows Terminal 用 Ctrl+Enter） |
| 复制上一条回复 | Ctrl+X |
| 贴图片 | Ctrl+V（Windows 用 Alt+V），或直接拖进终端 |
| 跑 shell 命令并把输出交给模型 | `!命令` |
| 跑 shell 命令但**不**给模型看 | `!!命令` |
| 用外部编辑器写长输入 | Ctrl+G |

**限制与降级**
- 外部编辑器按 `externalEditor` → `$VISUAL` → `$EDITOR` → 系统默认 依次回退。
- 图片显示取决于终端能力；`showImages` 可关闭。

## 三、会话

**前置条件**：默认开启会话持久化；`--no-session` 可关闭，`--session-dir` 换存储位置。

**最小用法**
```bash
pi -c                    # 继续最近一次会话
pi -r                    # 从历史会话里挑
pi --session <路径或ID>   # 打开指定会话
pi --name "任务名"        # 启动时命名
```
交互界面里：`/resume` 挑会话 · `/new` 新建 · `/name` 命名 · `/session` 看统计 ·
`/export` 导出 · `/import` 导入 · `/share` 分享为私密 gist。

**会话是一棵树，怎么用**
- `/tree` —— 跳到会话里**任意一点**并从那里继续；
- `/fork` —— 从某条历史用户消息**新建**一个会话；
- `/clone` —— 在当前位置**原地复制**一份。

**限制与降级**
- ⚠️ **换会话（新建/恢复/分叉/克隆/导入）会把扩展全部卸载重装**。扩展作者要在关闭通知里清理、
  在启动通知里重建状态。
- ⚠️ **扩展可以否决换会话**。此时命令返回「成功但已取消」——不是失败，也不是没执行成功，而是**被拦下了**。
- 离开分支时 Pi 会**提议**把放弃的那条线摘要后注入新分支；这是可取消的。

## 四、上下文压缩

**前置条件**：无需配置，超限自动触发；也可手动。

**最小用法**
```
/compact                 # 手动压缩
/compact 只关注数据库部分   # 带指示，聚焦摘要方向
```

**触发规则**：上下文 > 模型窗口 − 预留额度（`reserveTokens` 默认 16384）。
保留最近约 `keepRecentTokens`（默认 20000）token 的原文，更早的内容替换为摘要。两者都可在
用户级或项目级设置里改。

**限制与降级**
- ⚠️ **压缩不删历史**：它替换的是「发给模型的那份内容」，会话里的原始记录仍在。
- ⚠️ **摘要本身要调用模型，花费计入会话总量**。压缩不是免费操作。
- 压缩可以由扩展接管（自定义摘要）；也可以被扩展取消。
- ⚠️ 溢出触发的压缩之后，Pi 可能**重试**刚被中断的那一轮。

## 五、工具

**前置条件**：默认全部启用。

**最小用法**：不用手动调用——模型自己决定。用参数控制可用范围：
```bash
pi --no-tools                    # 全关
pi --no-builtin-tools            # 只关内置
pi -t read,grep                  # 只开这些
pi -xt bash,write                # 排除这些
```

**7 个内置工具**：`bash` `edit` `find` `grep` `ls` `read` `write`

**限制与降级**
- ⚠️ **启用哪些工具会改变系统提示词**——每个工具都往提示词里加一段说明。工具集不同，模型看到的输入不同。
- ⚠️ **并发规则**：一批调用默认并行；**只要有一个工具声明不能并发，整批转为串行**。
- ⚠️ **`edit` 的每处修改都对照原始文件匹配、禁止重叠**，不是依次作用在改过的文件上。
- `read` 会按行数或字节数截断，需要续读用 `offset`。
- ⚠️ **扩展可以改写工具参数**（且不重新校验），也可以整体替换 bash 后端。装了扩展之后，
  「模型请求的」和「实际执行的」可能不同。

## 六、扩展

**前置条件**：`-e <路径>` 加载单个扩展；或放到用户级/项目级扩展目录；`--no-extensions` 全禁用。
⚠️ **项目本地扩展只有在项目被信任之后才加载。**

**最小用法**
```bash
pi -e ./my-extension.ts
```
扩展可以：注册工具、注册斜杠命令、监听生命周期事件、提供自定义界面、改写输入与工具参数、
替换 bash 后端、贡献技能/提示词/主题路径。

**限制与降级**
- ⚠️ **输入处理是五步，扩展的输入钩子排第二**：先匹配扩展命令（**命中则输入钩子根本不触发**）→
  输入钩子 → 技能展开 → 模板展开 → 交给模型。**钩子看到的是没展开的原始文本。**
- 多个扩展都改写输入时**依次叠加**；但只要有一个声明「我处理了」，**第一个胜出**并跳过模型。
- **项目信任**：第一个明确给出「信任/不信任」的扩展说了算，并压制内置提示；返回「未决定」才交给下一个。
- ⚠️ 扩展抛错不会静默——会发出扩展报错事件。

## 七、模型与厂商

**前置条件**：至少一个厂商凭据。

**最小用法**
```bash
pi --provider anthropic --model sonnet     # 指定厂商与模型
pi --model anthropic/claude-sonnet:high    # 带思考等级
pi --list-models                           # 列出可用模型
pi --api-key <key>                         # 直接给 key
```
交互界面：`/login` 登录（含 OAuth）· `/logout` 退出 · `/model` 换模型 ·
`/scoped-models` 设定 Ctrl+P 轮换范围 · `/settings` 调思考等级。

**登录时会遇到什么**：`/login` 之后，Pi 只会用 4 种方式问你——让你输入文本、输入密文（不回显）、
从列表里选一项、或者把授权码粘回来；并且只会用 4 种方式通知你——提示信息、「打开这个网址」、
设备码（给你一个码和一个验证地址）、进度。凭据最终只有 **API key** 和 **OAuth** 两种。

**限制与降级**
- **40 个内置文本厂商** + 1 个图像厂商；另有一个测试用假厂商。
- ⚠️ **「粘贴授权码」和浏览器回调是在赛跑**：浏览器那边先成功，粘贴提示就会自动消失——这是正常的，
  不是出错。
- 有些厂商（如 Bedrock）会先让你选认证方式（Bearer token / AWS profile / 现有 AWS 凭据链）；
  选后两者时 Pi **不会把你的 AWS 凭据复制进自己的存储**，只是记下用哪种方式。
- **思考等级 7 档**（关闭/最小/低/中/高/超高/最大），可为每档配置 token 预算。
- ⚠️ **两层重试**：厂商层（同一请求内，扩展看不到中间失败）和会话层（**重新发起整个请求**，
  相关扩展钩子**会再触发一遍**）。
- ⚠️ **可用模型清单是构建时生成的**，不在源码仓库里。`--list-models` 反映的是安装后的实际情况。

## 八、RPC（程序驱动 Pi）

**前置条件**：Pi 已安装并有凭据。

**最小用法**
```bash
pi --mode rpc [--provider anthropic] [--model sonnet] [--no-session]
```
之后通过标准输入发命令、标准输出收事件（逐行 JSON）。

**能做什么**：提问、纠偏、追加后续消息、中止；查状态与消息；设置/轮换模型与思考等级；
设置队列模式；压缩；控制自动重试；执行 bash；会话统计、导出、切换、分叉、克隆、树；取命令列表。
**32 个命令、24 个事件、9 种界面请求。**

**限制与降级**
- ⚠️ **提问/纠偏/追加消息的返回只是「已收到」**，不是「已完成」。真正结果通过**后续事件**到达。
  把它当完成信号，会在错误的时刻认为任务结束。
- ⚠️ 有些命令返回「成功但已取消」——用户或扩展中止了操作。
- ⚠️ **界面请求需要你回应**（选择、确认、输入、编辑器）；不回应会挂住那次交互。
- ⚠️ **有 3 个事件会实际发出但官方文档未列**；只按文档实现的客户端会漏掉它们。
- **另有一套完全不同的多会话协议**（二进制 CBOR，9 个命令），用于附加/分离多个会话。**两套不要混。**

## 九、SDK（把 Pi 当库嵌入）

**前置条件**：Node 项目。

**最小用法**：官方 13 个示例按序覆盖——最小可用、自定义模型、自定义提示词、技能、工具、扩展、
上下文文件、提示词模板、密钥与 OAuth、设置、会话、完全控制、会话运行时。

**限制与降级** 🟡 —— 接口细节尚未逐条查完，请以官方 `sdk.md` 与示例为准。

## 十、设置与环境变量

**前置条件**：用户级 `~/.pi/agent/settings.json`；项目级 `<项目>/.pi/settings.json`。

**最小用法**：交互界面用 `/settings` 改常用项；其余直接编辑 JSON。
**49 个设置项**，覆盖压缩、分支摘要、重试、终端与图像、思考预算、Markdown 渲染、默认模型与厂商、
队列模式、主题、外部编辑器、shell 路径与前缀、扩展与技能与主题来源、遥测与分析开关等。

**环境变量（一共 26 个名字；下表是你会主动设置的那些）**

| 想做什么 | 变量 |
| --- | --- |
| 换配置目录 | `PI_CODING_AGENT_DIR` |
| 换会话目录（`--session-dir` 优先级更高） | `PI_CODING_AGENT_SESSION_DIR` |
| 完全不联网 | `PI_OFFLINE` |
| 关遥测 | `PI_TELEMETRY` |
| 跳过版本检查 | `PI_SKIP_VERSION_CHECK` |
| 改 `/share` 的查看地址 | `PI_SHARE_VIEWER_URL` |
| 走代理 | `HTTP_PROXY` / `HTTPS_PROXY` |
| 打开实验特性（**官方文档未写**） | `PI_EXPERIMENTAL=1` |
| 改 OAuth 回调主机（**官方文档未写**，默认 `127.0.0.1`） | `PI_OAUTH_CALLBACK_HOST` |
| 延长 Anthropic/Bedrock/OpenAI 的缓存保留 | `PI_CACHE_RETENTION=long` |
| 调终端 ESC 判定超时 | `PI_TUI_ESC_TIMEOUT` |

**工具里能读到的会话信息**：`bash` 执行命令时，Pi 会往子进程环境里写 5 个变量——
`PI_SESSION_ID`、`PI_SESSION_FILE`、`PI_PROVIDER`、`PI_MODEL`、`PI_REASONING_LEVEL`。
**写之前会先把同名的旧值删掉**，所以不会串到上一次会话的值；`exposeSessionEnvironment: false` 可关掉。
注意这 5 个是 Pi **写给你**的，不是你设置给 Pi 的。

**限制与降级**
- 项目级设置需要项目被信任才生效（`/trust` 可持久保存决定）。
- `defaultProjectTrust` 决定默认是询问、信任还是拒绝。
- ⚠️ **配置目录/会话目录这两个变量名是拼出来的**，前缀取自产品名（默认 `pi`）。改品牌名之后要用
  `${新名大写}_CODING_AGENT_DIR`，**旧的 `PI_` 前缀会失效**。
- ⚠️ 另有一批调试/性能开关（`PI_TIMING`、`PI_STARTUP_BENCHMARK`、`PI_TUI_DEBUG`、`PI_DEBUG_REDRAW`、
  `PI_TUI_WRITE_LOG`、`PI_CLEAR_ON_SHRINK`）官方文档没写，**不建议当稳定接口用**。

## 附录：怎么核对这份文档

内容都来自固定版本 `086c32e7`。可以自己重跑：

```bash
cd pi-go
python3 tools/gen-feature-ids.py --pi-repo /path/to/pi \
        --check-providers tools/expected-providers.txt
python3 tools/test_gen_feature_ids.py     # 抽取器自身的负向控制
python3 tools/check-doc-counts.py --pi-repo /path/to/pi   # 文档里的数字必须和生成器一致
python3 tools/mutation-sweep.py --pi-repo <pi>   # 故意改坏抽取器，测试必须变红（较慢）
```

**退出码 0 只说明**：固定版本可读、抽取器没触发自身守卫（无法归类的调用 / ID 撞车 / 成员数不符）、
**厂商那一类**与一份独立期望清单集合相等。

**它不说明**：其余 23 类**没有**与另一份独立权威清单做集合比对，所以退出码 0 的意思是
「**没有发现不一致**」，而不是「**已证明完整**」；它也不替代逐文件独立遗漏审计。

标 🟡 的小节表示**我们还没查完**，不表示「查完了只有这些」。
